# Exact download instructions

Download the 15 exact nucleotide accessions in CONFIRMATORY_COHORT_A.csv from NCBI Nucleotide.

For each:
1. Search the accession only, e.g. NC_017463.1 (do not add .fasta).
2. Open the exact accession/version.
3. Select the whole nucleotide record in FASTA format.
4. Save it.
5. Rename to <accession>.fasta without editing the contents.

Put only the 15 primary files into:
GC_Skew_Confirmatory_A_15_FASTA

ZIP that folder and upload the ZIP to this conversation.

Do not download the reserve files unless a primary accession fails the frozen provenance/eligibility gate.
